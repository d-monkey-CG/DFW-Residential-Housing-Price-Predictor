# DFW-Residential-Housing-Price-Predictor
This ML model is trained on 5 to 7 years worth of Appraisal District data (2019 - 2025, where available) from the 3 largest counties by population in the DFW area: Dallas County, Tarrant County, and Collin County.

This repository includes the data files used and most of the wrangling done to combine the data sets and create a standardized version for all three counties before training the model. The link to the full final completed data file and the files used to create it are located in this folder: https://drive.google.com/drive/folders/1IEqxMkUkMTB1CeMmpMsQK2UbdKfBXALm?usp=share_link
